## Что это и зачем

Складская система 3PL-склада под одного клиента, Chapman (юрлицо Bastion Import Chapman MCHJ, сигареты Chapman)
Заказы приходят из Smartup клиента и Excel-файлами через Telegram-бота, склад собирает их по заявкам СкладБота,
сканирует коды маркировки (КИЗ) на станции и отгружает; TakSklad отдаёт клиенту файлы КИЗ, логистике файл маршрутов,
клиенту суточный отчёт, Антону алерты, и держит учёт кодов, возвратов и биллинга

- Заказ: сделка Smartup (слоты 12:00, 15:00, 17:50 по Ташкенту, берутся только сделки в статусе `B#N` «В обработке»)
  или файл `Шаблон_отправки_заказов_на_склад_ДД_ММ_ГГГГ.xlsx` в бота с датой отгрузки
- Один Smartup ID это один заказ и одна заявка СкладБота (`WH-R-…`); склад собирает по заявке
- КИЗ: блок 35 знаков, короб 67 знаков (короб Chapman это 50 блоков, короб KSSL тоже 50); сканирует станция склада
  HOME-PC (Windows-программа `TakSklad.exe`), веб-станция на `chapman.taksklad.uz/` в работе и выключена
- Выход: файл КИЗ по каждому залитому файлу в клиентскую группу, отчёт логистики в шаблоне «Orders via Excel» (35 колонок,
  город и область двумя файлами плюс приписка) в 17:50, дейли СкладБота клиенту, возвраты (по перечислению только
  через одобрение Антона в боте), ежемесячный биллинг Chapman
- Для кого: Антон (владелец, единственный, кто решает), склад, логистика, команда Chapman

## Грабли и запреты коротко

- Клиентский вывод не менять без «было и стало» и согласования (контракт в `CLAUDE.md`), Telegram-маршруты только с contract-тестами и no-send verifier
- Перед выкатом: `docker ps -a` и `HOLD_*` в `/opt/stacks/taksklad/` (остановленный руками воркер `compose up` поднимет), полный sha,
  cutover-скрипт файлом, не через stdin; согласовать окно с соседними сессиями (память `taksklad-parallel-sessions-deploy-coordination`)
- Перенос даты правкой в базе: уже ездивший заказ в маршруты нового дня не попадает; дата в заявке СкладБота не меняется
- Сделка Smartup вне «В обработке» для слота не существует; «Архив» не доказывает доставку
- Таймаут POST к СкладБоту это неизвестность: сверять read-back, не повторять вслепую (`/root/recover_ambiguous.py`)
- Удалённый штатно заказ держит отчёт логистики до выката #221, выпуск вручную
- Сборный короб с заводской этикеткой: экспедитор может пробить агрегат на 50 блоков одного вида
- Вечерний алерт «отчёт заблокирован» в 17:51 штатен, поломка это алерт без «разблокирован»
- Таймаут десктопа 8 с прячет медленный backend; `handshake timeout` это обрыв канала станции, КИЗы в очереди
- Новый роут поднимает счётчики RBAC в двух тестах; новая миграция ломает 11 мест с головой Alembic; новая зависимость требует SBOM
- Рабочие данные в корне (`TakSklad_data.json`, очереди, `credentials.json`) не трогать: страховка склада
- Полный список: память проекта и `База знаний/Грабли/` (ссылки в хабе `База знаний/TakSklad/00-TakSklad.md`)
